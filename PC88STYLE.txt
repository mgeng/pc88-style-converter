================================================================
 PC88STYLE.txt
 PC-8801 (PC-88) 風 画像変換のための特徴まとめ
 ── このアプリの画像処理(JavaScript)の仕様書を兼ねる ──
================================================================

【目的】
 アップロードされた任意の画像を、NEC PC-8801 (とくに mkII SR 以降、
 通称「PC-88」) のグラフィック画面で表示されたような見た目に変換する。
 画像処理はすべてブラウザ上の JavaScript (Canvas / ImageData) で完結させる。


----------------------------------------------------------------
1. 解像度 (Resolution)
----------------------------------------------------------------
 PC-88 のグラフィック画面の代表的なモード:

  - 640 x 200  : アナログ8色モード。ホビー用途で最も多用された。
                 ゲーム・デモ・CG集はほぼこれ。本アプリの基準とする。
  - 640 x 400  : 高解像度モノクロ(主に業務・テキスト寄り)。
  - 320 x 200  : 一部のモード。

 重要なのは「縦が 200 ライン」しかないこと。
 → 元画像を 640 x 200 (または 320 x 200) に縮小してから処理する。

 ★ ピクセルが正方形ではない (ドットが縦長)
   640x200 を 4:3 のブラウン管に表示するため、1ドットは横より縦に長い。
   横:縦 ≒ 1 : 2 に近い縦長ドット。
   → 変換時は 640x200 で処理し、表示時に縦方向へ約2倍拡大して
     当時のアスペクト比(横長の絵)を再現するとそれらしくなる。


----------------------------------------------------------------
2. 色 (Color / Palette)
----------------------------------------------------------------
 ★ 同時発色は基本「8色」
   640x200 モードでは画面に同時に出せる色は 8 色。

 ★ デジタル8色 (初期 / PC-8801 無印・mkII)
   R, G, B をそれぞれ ON / OFF するだけ → 2^3 = 8 色固定。
     黒   (0,0,0)
     青   (0,0,255)
     赤   (255,0,0)
     マゼンタ(255,0,255)
     緑   (0,255,0)
     シアン (0,255,255)
     黄   (255,255,0)
     白   (255,255,255)
   原色が強く、中間色が無いのが特徴。これが「8ビットPCらしさ」の核。

 ★ アナログ8色 (mkII SR 以降)
   512色 (R/G/B 各8階調 = 8x8x8) のパレットから 8 色を選んで使える。
   ただし「同時8色」という制約は同じ。
   → CG では落ち着いた中間色のパレットも組めたが、
     階調表現はディザリングに頼った。

 本アプリの方針:
   (a) デフォルトは「デジタル8色」に減色 → いちばんPC-88らしい。
   (b) オプションで「アナログ風」: 画像から代表8色を選ぶ
       (メディアンカット等)パレットモードも用意できる。


----------------------------------------------------------------
3. ディザリング (Dithering) ── 最重要
----------------------------------------------------------------
 たった8色で写真やイラストの階調・グラデーションを表現するため、
 PC-88 の CG は「ディザリング(網点・市松模様)」を多用した。
 これが PC-88 らしさを決める最大の要素。

 代表的な手法:

  - 順序付きディザ (Ordered / Bayer dither)
      4x4 や 2x2 のしきい値マトリクスで規則的な網目模様を作る。
      → 当時の「タイルパターン」「メッシュ」の質感に近い。
      → くっきりした幾何学的な網点が出てレトロ感が強い。【推奨デフォルト】

  - 誤差拡散 (Floyd-Steinberg)
      誤差を隣接ピクセルへ拡散。なめらかだが「砂状」になる。
      写真寄りの素材ではこちらが自然なことも。オプションで選択可。

 ポイント:
   - 縦長ドット + 横長の網目 → 独特の「走査線まじりの網点」感。
   - 強いディザほど 80年代CGっぽい。弱いとただの減色画像になる。


----------------------------------------------------------------
4. その他の質感 (それらしさを足す要素)
----------------------------------------------------------------
 - 走査線 (Scanline)
     ブラウン管表示の横方向の暗い線。縦2倍拡大時に1ラインおきに
     軽く暗くすると CRT 風になる。(オプション)

 - 輪郭・ベタ塗り
     当時の手描きCGは「線画 + ベタ + ディザによる陰影」。
     写真変換では再現しにくいが、コントラストを上げ気味にすると寄る。

 - にじみ / ボケは「ほぼ無い」
     ドットはくっきり。アンチエイリアスをかけない (nearest neighbor)。
     表示拡大時も補間しない (canvas image-rendering: pixelated)。


----------------------------------------------------------------
5. 変換パイプライン (JavaScript 実装方針)
----------------------------------------------------------------
 入力画像 (任意サイズ)
   ↓ ① リサイズ: 横 640 (or 320)、縦 200 に縮小 (nearest / 平均)
   ↓ ② 前処理(任意): 明るさ・コントラスト・彩度の調整
   ↓ ③ 減色 + ディザ:
        - パレット決定 (デジタル8色 固定 / アナログ8色 抽出)
        - 各ピクセルを Bayer 4x4 もしくは Floyd-Steinberg で8色へ
   ↓ ④ 表示用拡大: 縦を約2倍 (縦長ドット再現)、補間なし(pixelated)
   ↓ ⑤ 後処理(任意): 走査線オーバーレイ
   出力 (Canvas → PNG ダウンロード可)

 すべて Canvas 2D の getImageData / putImageData で完結。
 外部ライブラリ・サーバー処理は不要。


----------------------------------------------------------------
6. UI に出すパラメータ(案)
----------------------------------------------------------------
 - パレット : [デジタル8色] / [アナログ8色(自動抽出)]
 - ディザ   : [Bayer 4x4(推奨)] / [Floyd-Steinberg] / [なし]
 - 解像度   : [640x200(推奨)] / [320x200]
 - 明るさ / コントラスト / 彩度 : スライダー
 - 走査線   : ON / OFF
 - 縦長ドット再現(縦2倍表示) : ON / OFF
 - 画像ダウンロード (PNG)

================================================================
 まとめ: 「8色」「強いディザ(網点)」「縦長ドット」「くっきりドット」
 この4つを押さえれば PC-88 らしさは再現できる。
